# 고등 나이스 치트시트

나이스를 쓰다 막혔을 때, 지금 겪고 있는 증상으로 해결 방법을 빨리 찾는 사이트입니다. 고등학교 교무 업무를 시기 네 개로 나누어 사례 63건을 정리했습니다.

**👉 [바로 열기](https://teachgrapher.github.io/neischeatsheet/)**

## 어떻게 되어 있나

첫 화면에서 시기를 고르거나, 증상을 그대로 검색창에 붙여넣으면 됩니다.

| 시기 | 기간 | 사례 |
|---|---|---|
| 학기 준비 및 학기초 | 2월 ~ 3월 | 19건 |
| 학기 중 | 4월 ~ 6월 · 9월 ~ 11월 | 32건 |
| 학기말 성적처리 | 7월 · 12월 | 40건 |
| 학년말 및 대입 전송 | 8월 말 · 1월 ~ 2월 | 29건 |

한 사례가 여러 시기와 여러 영역에 동시에 걸릴 수 있습니다. 전입생 문제는 학적이면서 전출입이고, 학기초에도 학기 중에도 뜹니다.

찾는 방식은 세 가지입니다.

- **시기로 좁히기** — 첫 화면의 시기 카드를 누릅니다. 목록은 문의가 많은 순입니다.
- **증상으로 검색하기** — 첫 화면 검색창에 오류 메시지를 그대로 붙여넣어도 됩니다. 제목뿐 아니라 절차 본문과 숨은 키워드까지 훑습니다.
- **트리맵으로 훑어보기** — 문의 건수를 넓이로 그린 지도입니다. 어떤 문제가 제일 자주 터지는지 한눈에 보입니다.

사례를 펼치면 세 줄 요약이 먼저 나오고, 해결 절차, 주의 사항, 배경 설명 순으로 이어집니다. 사례마다 그 사례로 바로 열리는 링크를 복사하거나 한 건만 PDF로 뽑을 수 있습니다.

## 인쇄물

시기별 책자 PDF가 [`pdf/`](pdf) 폴더에 있습니다. 표지, 차례, 사례 본문 순이고 쪽번호가 붙어 있습니다. 사례를 고친 뒤 다시 뽑으려면 이렇게 합니다.

```bash
node make-books.js          # print-p1.html ~ print-p4.html 생성
```

만들어진 HTML을 브라우저로 열고 Ctrl+P를 누르면 됩니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 첫 화면. 시기 카드, 전체 검색, 트리맵 링크 |
| `list.html` | 시기별 사례 목록. `list.html?p=p2#사례id`로 특정 사례를 바로 엽니다 |
| `treemap.html` | 문의 건수를 넓이로 그린 트리맵 |
| `cases.js` | **사례 원본.** 화면 셋은 모두 이 파일만 읽습니다 |
| `check-cases.js` | 데이터 검증. `node check-cases.js` |
| `make-books.js` | 인쇄용 책자 HTML 생성 |
| `checklist.md` | 남은 일 |
| `context-notes.md` | 설계할 때 정한 것과 그 이유 |

빌드 도구나 프레임워크를 쓰지 않습니다. `index.html`을 더블클릭해서 열어도 그대로 동작합니다. 그래서 사례 데이터가 JSON이 아니라 `.js` 파일입니다. 파일로 직접 열면 `fetch`가 막히기 때문입니다.

## 사례 추가하기

`cases.js`의 `CASES` 배열에 항목을 하나 넣습니다.

```js
{
  id: 'jeonipsaeng-sugang-matching',   // 한 번 정하면 바꾸지 않습니다. 주소로 바로 여는 데 씁니다
  short: '전입생 수강편성 회색',        // 트리맵 칸에 넣는 짧은 이름. 열두 자 안팎
  asks: 42,                            // 나이스광장에 올라온 비슷한 질문 수. 정렬 기준입니다
  title: '당해 학기 전입생이 수강생편성 화면에서 회색으로 비활성화되어 선택되지 않습니다',
  periods: ['p1', 'p2'],               // 이 사례가 떠야 하는 시기
  areas: ['학적', '전출입'],            // AREAS에 있는 이름만 씁니다
  path: '학적 › 전입관리 › 전입관리 › 종합자료검색',
  keywords: '전입생 수강생편성 회색 비활성화',   // 검색에만 쓰이고 화면에는 안 보입니다
  summary: ['...', '...', '...'],      // 세 줄 요약
  steps: [ { name: '...', path: '...', body: '...' } ],
  notes: ['...'],                      // 주의 사항
  why:   ['...'],                      // 왜 이렇게 되는지
  related: ['다른-사례-id']              // 양방향으로 걸어야 합니다
}
```

제목은 **업무 이름이 아니라 나이스에서 눈에 보이는 증상**을 그대로 씁니다. 막힌 사람이 검색창에 칠 말과 같아야 찾아집니다.

상황에 따라 절차가 통째로 갈리면 `steps` 대신 `branches`를 씁니다.

```js
branches: [
  { name: '당해 학년도 자료', when: '아직 마감 전이라면', steps: [ ... ] },
  { name: '과년도 자료',     when: '이미 마감했다면',   steps: [ ... ] }
]
```

본문 안에서 `{저장}`처럼 중괄호로 감싼 말은 나이스 버튼 모양으로 표시됩니다.

넣은 뒤에는 반드시 검증을 돌립니다. 영역 이름 오타, 한쪽만 걸린 연결, 짧은 이름 중복 같은 것을 잡아 줍니다.

```bash
node check-cases.js
```

`main`에 올리면 깃헙 액션이 같은 검증을 한 번 더 돌립니다.

## 문의 건수는 무엇인가

나이스광장 질의응답에 올라온 비슷한 질문의 수입니다. 특정 학교의 문의 수가 아닙니다. 목록을 정렬하는 기준이며 40건이 넘으면 "자주 나오는 문제" 표가 붙습니다. 일부 사례는 실제 집계가 없어 중요도로 어림한 값이 들어 있습니다. 어느 사례가 그런지는 `context-notes.md`에 적어 두었습니다.

## 만든 이유

강원도 정선 여량고등학교에서 교무 업무를 하며 겪은 것과, 나이스광장 질의응답에 반복해서 올라오는 것을 모았습니다. 나이스 화면은 개편될 수 있습니다. 메뉴 이름이 다르면 같은 자리의 메뉴를 찾아 보시고, 틀린 내용을 발견하시면 [이슈](../../issues)로 알려 주십시오.
